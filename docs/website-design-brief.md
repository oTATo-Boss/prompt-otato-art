# oTATo prompt 官网视觉设计简报

2026-10-04。用户确认第二个方向，并要求背景由软件真实截图延伸、展示不同功能界面，随后授权本地实现。本简报取代此前被否定的「入屏」方案。

## 目标与约束

优先传达独立创作者的个性、实验视觉和创作情绪。产品是免费的 Mac 提示词资料库，采用现有品牌蓝 `#2B5FFC` 与 oTATo 线稿 Logo。以 Awwwards、Webby Awards、FWA 的排版、视觉和交互品质为参照，不宣称获奖。

视觉主体采用当前软件界面；不把单张提示词封面当作整个品牌的背景。用户喜欢实体电脑展示、蓝底大字与随滚动变化的构图。软件没有变量模板功能，不展示巨大双花括号或替换变量；不宣传 AI 生成、自动保存、正文全文搜索、iCloud 同步，不采用等待发布或倒计时叙事。

## 交互与响应式

根据用户最新要求改为沉浸式滑动：章节在视口内停留，滚动直接控制构图。首屏字标依次入场，词库从右侧倾斜状态展开；蓝底大字错序出现，编辑页从屏幕外进入；电脑由整机推进到真实软件特写；快捷搜索浮层上升、放大，结尾 CONTINUE. 逐字揭示。原生滚轮和触摸滚动保持浏览器行为，提供直接章节跳转。

按用户最新要求移除全部弹窗及相关入口；顶部加入 GitHub 仓库按钮，顶部右侧、首屏右侧和末屏蓝色按钮统一为下载入口，预留 GitHub Releases。页面明确说明仅支持 macOS 14+。

手机和较窄的平板竖屏改为上下构图，横向桌面保留双栏；高度不足 620px 时回到连续阅读。系统减少动态效果或页尾开关停用动效和固定章节，保留所有内容与操作，并尽量保持当前章节位置。

## 自检重点

| 项目 | 验收重点 |
| --- | --- |
| 排版 | 两套真实字体；中文语义断行；大字保有张力，正文可读。 |
| 留白 | 标题、界面、说明和章节导航不遮挡；保留有节奏的章节间距。 |
| 视觉层级 | 字标与真实词库建立品牌，编辑与搜索说明产品，电脑提供实体感。 |
| 色彩 | 品牌蓝准确；小字、图标与操作对比充足。 |
| 动效 | 滚动编排具有明显的展开、入场和镜头变化；画面留有阅读阶段；停止滚动不持续计算；减少动效有效。 |
| 微交互 | 下载与 GitHub 链接、章节导航、键盘焦点和减少动效开关有效。 |
| 响应式 | 桌面、宽屏、平板、小手机、横屏不产生页面横向溢出。 |
| 原创性 | 使用本品牌、真实软件界面和具体创作语境，避免通用功能卡片堆砌。 |
