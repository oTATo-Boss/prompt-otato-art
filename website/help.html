安装与备份

安装

  1. 在官网点击「下载 macOS 版」，下载 DMG 安装包。软件支持 macOS 14 及以上版本。
  2. 打开 DMG，把 oTATo Prompt.app 拖到「应用程序」。
  3. 从「应用程序」启动。首次使用是空资料库，可以新建提示词或导入 UTF-8 编码的 .md / .txt 文件。

首次打开：未公证版本

当前发行包尚未经 Apple 公证。首次打开时，macOS 可能显示「无法验证开发者」或「Apple 无法检查是否包含恶意软件」。DMG 内包含可离线阅读的「安装说明.pdf」。

  1. 先把 App 拖入「应用程序」，然后双击尝试打开一次。
  2. 若系统阻止打开，点「完成」，打开「系统设置 → 隐私与安全性」。
  3. 向下找到「安全性」，在关于 oTATo Prompt 的提醒旁点「仍要打开」。
  4. 按系统提示验证密码或 Touch ID，再在确认窗口中点「打开」。

请确认安装包来自本官网。受公司或学校管理的 Mac 可能限制此操作；遇到「已损坏」或「将损坏电脑」的提醒时，请停止安装，重新下载并反馈。步骤依据 Apple 官方说明。

日常使用

搜索匹配标题和标签。默认按 Option + Space 打开快速搜索；快捷键可以在设置中修改。编辑正文后点击「保存」或按 ⌘S。直接返回或切换提示词会放弃未保存的修改。

完整备份

在「设置 → 数据 → 完整资料库 → 备份与恢复」导出 .otatoarchive。归档包含提示词、文件夹、标签、封面和废纸篓内容。普通 Markdown 导出不能替代完整备份。

恢复归档会替换当前资料库；应用先自动保存原库的安全备份。建议在升级、换电脑或大量整理资料之前，额外导出一份完整归档。

更新

正式版默认每小时检查一次新版本，发现更新后显示提示，由你选择安装。可以在「设置 → 关于」关闭自动检查或手动检查，也可以从应用菜单选择「检查更新…」。安装新版本会保留本机资料库；安装前仍建议备份。
