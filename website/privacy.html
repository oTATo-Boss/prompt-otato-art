隐私说明

更新于 2026 年 10 月 4 日

你的资料库

oTATo prompt 无需账号。提示词、文件夹、标签、封面与应用内备份存储在这台 Mac 的应用沙盒中；当前版本不提供云同步，也不将资料库内容上传到更新服务。

检查与下载更新

正式版使用 Sparkle 检查版本和下载更新。自动检查默认开启，可在「设置 → 关于」关闭。检查时会连接 prompt.otato.art；下载安装包时会访问 GitHub 的下载服务。这些服务会接收完成网络请求所需的信息，例如 IP 地址。应用关闭 Sparkle 的系统分析信息提交。

官网与反馈

官网使用 Cloudflare 托管，下载包由 GitHub 托管。页面的字体和图片从本站加载，未加入广告或访问分析脚本。服务平台自身的数据处理见 Cloudflare 隐私政策与 GitHub 隐私说明。

通过 GitHub Issues提交的反馈可能公开显示，请自行删去私人提示词和截图中的敏感信息。
